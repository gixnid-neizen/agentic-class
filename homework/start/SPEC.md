# SPEC

## Requirement

Я не хочу видеть задачи без видимых названий или неверный счетчик.

## Acceptance tests

### Переименование

При переименовании в некорректное (пробел, табуляция, неразрывный пробел U+00A0 или ничего не введено) должно выводиться уведомление: окно alert с текстом "Название не может быть пустым". Сама задача и ее название при этом меняться никак не должны, а лишние пробелы по краям названия должны обрезаться.

- Переименовываю "Сдать лабораторную" в 4 пробела, появляется alert с текстом и кнопкой OK, название остается "Сдать лабораторную".
- Переименовываю задачу в " Хлеб " → название становится "Хлеб".

### Пустая задача

Задача с пустым названием не должна отображаться ни в одной из вкладок: Все, Открытые, Готовые.

- Перехожу во все доступные вкладки и не вижу ни одной задачи с пустым названием.

### Счётчик

Счётчик "Открытых" не должен считать задачи с пустым названием.

- Вижу счетчик "Открытых". На стартовых данных вижу "Открытых: 1".

## Non-goals

- Не добавляй лишний функционал и визуал, не необходимый для решения поставленных задач.
- Не пиши какие-либо тесты.
- Названия и параметры существующих функций в `tasks.ts` или `src/App.tsx` не меняй.

## Files in scope

`src/tasks.ts` и `src/App.tsx`

## Definition of done

`npm test` без ошибок, `npm run build` проходит, на экране «Открытых: 1» и пустой строки нет.
